# awesome-design-md

Colección de [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (licencia en `LICENSE`).
Cada carpeta de `design-md/<web>/` contiene un `DESIGN.md` con el sistema visual de esa web.

## Cómo usarla

1. Elige la carpeta de `design-md/` que mejor encaje con lo pedido (la marca citada o la estética más cercana).
2. Lee `design-md/<web>/DESIGN.md` **entero** antes de escribir ninguna línea de UI.
3. Úsalo como fuente de verdad de los tokens (colores, tipografía, radios, sombras, espaciado, estados) y del tono visual de los componentes.
4. No copies logos, nombres, marcas registradas ni textos de la marca: toma solo el sistema visual y aplícalo a la identidad de posiq.

Si se pide un DESIGN.md propio, usa uno o varios de estos como plantilla de estructura.
